# 213 Veritas Design System

Visual identity and design tokens for 213 Veritas — white-glove managed IT services for law firms, medical practices, and high-net-worth residences.

## Principles

- **Navy-dominant** institutional palette on white
- **Playfair Display** (serif) for headings, **DM Sans** for body
- **WCAG AAA** contrast compliance — no exceptions
- **All assets SVG** — no raster images
- Engraved-style architectural ornaments sourced from LA Union Station
- Scarlet and green accents used sparingly as design details

## Tokens

All design tokens are defined in `tokens.css` as CSS custom properties.

- `svg/divider-sm.svg` — minimal section divider

## Typography

- **Headings:** Playfair Display 600 (42px hero / 30px section / 19px card)
- **Body:** DM Sans 400 (16px body / 14px card / 13px labels)
- **Eyebrow labels:** DM Sans 600 (11px, uppercase, 0.14em tracking, scarlet)
